진주 운전자 버스 앱 단말기 아두이노 구현
# 기능
1. NFC 인식하여 잔액, 누가탔는지 등을 서버에 전달
2. 하차벨을 누르면 하차표시
3. 서버로부터 하차 승객을 전달받아 표시하고, 해당역에서 하차 승객이 있으면 하차표시

# 진행 정도
1번과 2번 기능 구현 완료. 디스플레이 테스트 완료. 기본적인 소스코드 구현 및 테스트 완료. 
WIFI 모듈 테스트 완료. 데이터 베이스 연동 과제 남음.

# 남은 과제
1. 백엔드 시스템과 WIFI 통신 연결.
2. 시뮬레이션 위한 패키지 포장. (전력 공급은 보조배터리 사용)
3. 시간적 여유가 허락한다면 휴대폰 NFC를 사용하여 서버와 통신하는 방식 추가. (현재는 주어진 NFC 카드를 통해 시뮬레이션 하도록 구성)
